# Assignment #4: Forms and Validation

**Student:** Oleksandr  
**Group:** SE-2528

The goal of this assignment is to understand how to create user-friendly forms with HTML, style them using Bootstrap form components, and apply form validation (both HTML5 built-in validation and Bootstrap validation classes).

## Project Structure

- `index.html` - **Part 1. Basic HTML Forms**:
  - Task 0: Simple Contact Form (proper `<label>` and form controls).
  - Task 1: Form with HTML5 built-in validation (`required`, `type="email"`, `maxlength`).
- `task2.html` - **Part 2. Bootstrap Forms**:
  - Task 2: Bootstrap Form Styling (grid, `form-control`, `form-label`, helper text).
  - Task 3: Bootstrap Validation Styles (`is-valid`, `is-invalid`, feedback messages).
- `task4.html` - **Part 3. Advanced Form Project**:
  - Task 4: Responsive Registration Form with Bootstrap Grid, radio buttons, checkboxes, dropdown select, password validation, and reset/submit buttons.
- `styles.css` - Custom styling and layout helpers.
